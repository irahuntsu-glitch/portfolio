# Портфолио

Перенос сайта с Framer на GitHub Pages. React + Vite + GSAP, весь контент — в двух
JSON-файлах, которые правятся через встроенную админку прямо из браузера.

## Что где лежит

```
content/site.json     тексты главной, ссылки, галереи (плёнка, плакаты, мероприятия)
content/cases.json    кейсы: заголовок, подпись, обложка, метрики, текст
public/media/         все картинки
src/components/       блоки главной
src/pages/            главная и страница кейса
src/lib/anim.js       весь GSAP: reveal, параллакс, бегущие ленты
src/admin/            админка (/admin)
```

## Запуск локально

```bash
npm install
```

```bash
npm run dev
```

Откроется на http://127.0.0.1:5177

## Публикация

Пуш в `main` запускает GitHub Actions (`.github/workflows/deploy.yml`): сборка →
деплой на Pages. Базовый путь считается сам — `/` для репозитория вида
`username.github.io` и `/<имя-репозитория>/` для любого другого.

Один раз нужно включить Pages: **Settings → Pages → Source → GitHub Actions**.

## Админка

Открывается по адресу `/admin` на самом сайте. Бэкенда нет — админка ходит в
GitHub API напрямую твоим личным токеном, который лежит только в localStorage
твоего браузера.

Как выпустить токен:

1. `github.com/settings/personal-access-tokens` → Generate new token
2. Repository access → Only select repositories → выбрать репозиторий сайта
3. Permissions → Repository permissions → **Contents: Read and write**
4. Скопировать токен и вставить в форму входа

Что можно делать: править тексты главной и подписи кнопок, загружать и
переставлять картинки в галереях, создавать и удалять кейсы, писать текст кейса
с заголовками, списками, цитатами, таблицами и картинками, прятать кейс в
черновики, менять порядок кейсов.

Кнопка «Сохранить и опубликовать» коммитит изменения в репозиторий, дальше
Actions пересобирает сайт — обычно минута-полторы.

На чужом компьютере обязательно выходить через «Доступ → Выйти и стереть токен».

## Анимации

Всё на GSAP + ScrollTrigger, под `prefers-reduced-motion` анимации отключаются:

- интро левой панели — таймлайн с масками по строкам
- обложки кейсов — раскрытие через `clip-path` и параллакс при скролле
- крупные тексты между блоками — сборка по словам
- галереи плёнки и плакатов — бесконечные ленты, ускоряются от скорости скролла
- страница кейса — раскрытие героя, блоки текста всплывают по мере появления

Высота страницы всё время меняется из-за ленивых картинок, поэтому в
`src/lib/anim.js` висит наблюдатель, который пересчитывает ScrollTrigger при
изменении высоты документа — иначе блоки ниже сдвига навсегда остаются скрытыми.
